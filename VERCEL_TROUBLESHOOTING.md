# Vercel Build Troubleshooting Guide

## Framework Settings in Vercel Dashboard

When setting up your project in Vercel, use these settings:

### Project Settings

1. **Framework Preset**: Select **"Vite"** or **"Other"**
   - If "Vite" is available, use it
   - If not, select "Other"

2. **Root Directory**: Leave empty (root of repository)

3. **Build Command**: 
   ```
   npm run build:vercel
   ```
   Or leave empty if using vercel.json

4. **Output Directory**: 
   ```
   frontend/dist
   ```

5. **Install Command**: 
   ```
   npm install
   ```
   Or leave as default

### Environment Variables

Add these in **Settings → Environment Variables**:

**Required:**
- `DATABASE_URL` - Your PostgreSQL connection string
- `GEMINI_API_KEY` - Your Google Gemini API key
- `NODE_ENV` - Set to `production`

**Optional:**
- `FRONTEND_URL` - Your Vercel deployment URL (auto-set)
- `PORT` - Server port (default: 3001)

### Common Build Errors & Solutions

#### Error: "Command exited with 1"

**Possible Causes:**
1. Missing dependencies
2. Prisma generate failing
3. Frontend build failing
4. Node version mismatch

**Solutions:**

1. **Check Build Logs**:
   - Go to Vercel Dashboard → Deployments → Click failed deployment
   - Check "Build Logs" tab
   - Look for the specific error message

2. **Verify package.json exists**:
   ```bash
   # Ensure root package.json has build:vercel script
   cat package.json
   ```

3. **Test build locally**:
   ```bash
   npm run build:vercel
   ```

4. **Check Node version**:
   - Vercel should use Node 18+ (configured in vercel.json)
   - Verify in Vercel Dashboard → Settings → Node.js Version

#### Error: "Prisma generate failed"

**Solution:**
- Prisma generate doesn't need a real DATABASE_URL
- The build script sets a dummy URL automatically
- If it still fails, check that `prisma` is in backend/package.json devDependencies

#### Error: "npm install failed"

**Solutions:**
- Check for package-lock.json files (they should be committed)
- Try clearing Vercel build cache
- Verify all package.json files are valid JSON

#### Error: "Frontend build failed"

**Solutions:**
- Check vite.config.js is correct
- Verify all frontend dependencies are in package.json
- Check for TypeScript/ESLint errors

### Step-by-Step Debugging

1. **Check Vercel Build Logs**:
   ```
   Vercel Dashboard → Your Project → Deployments → Failed Build → Build Logs
   ```

2. **Identify the failing step**:
   - Look for error messages
   - Check which command failed (install, generate, or build)

3. **Test locally**:
   ```bash
   # Test the exact build command
   npm run build:vercel
   
   # Or test individual steps
   npm run install:backend
   npm run install:frontend
   npm run generate:prisma
   npm run build:frontend
   ```

4. **Check file structure**:
   ```
   ├── package.json          ← Must exist at root
   ├── vercel.json           ← Must exist
   ├── api/
   │   └── index.js          ← Serverless function
   ├── backend/
   │   ├── package.json
   │   └── prisma/
   │       └── schema.prisma
   └── frontend/
       ├── package.json
       └── dist/             ← Generated by build
   ```

### Alternative: Manual Build Configuration

If automatic detection fails, manually configure in Vercel Dashboard:

1. **Go to**: Project Settings → General
2. **Override** these settings:
   - Framework: Vite
   - Build Command: `npm run build:vercel`
   - Output Directory: `frontend/dist`
   - Install Command: `npm install`
   - Root Directory: (leave empty)

### Quick Fixes

**If build keeps failing:**

1. **Clear build cache**:
   - Vercel Dashboard → Settings → Build & Development Settings
   - Click "Clear Build Cache"

2. **Redeploy**:
   - Go to Deployments
   - Click "Redeploy" on latest deployment

3. **Check environment variables**:
   - Ensure all required vars are set
   - Check for typos in variable names

4. **Verify git repository**:
   - Ensure all files are committed
   - Check that package.json and vercel.json are in root

### Testing Build Locally

```bash
# Simulate Vercel build
export NODE_ENV=production
npm install
npm run build:vercel

# Check output
ls -la frontend/dist
```

### Still Having Issues?

1. **Share the exact error** from Vercel build logs
2. **Check Vercel status**: https://vercel-status.com
3. **Review Vercel docs**: https://vercel.com/docs
4. **Check Node version compatibility**

### Success Indicators

Your build is successful when you see:
- ✅ All npm installs complete
- ✅ Prisma client generated
- ✅ Frontend build completes
- ✅ `frontend/dist` directory created
- ✅ Deployment shows "Ready" status
